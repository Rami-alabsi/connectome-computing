# Research Questions

## RQ1 — What biological structure matters computationally?
Test sparsity, degree distributions, recurrence, motifs, rich-club organization, modularity, hierarchy and long-range connectivity.

## RQ2 — Can biological motifs become computational primitives?
Candidate mappings:
- neuron → stateful processing node
- synapse → weighted communication edge
- microcircuit → processing unit
- recurrent loop → feedback/state
- hub → integration/routing resource
- module → processing subsystem
- sparse activity → event-driven execution

These are hypotheses, not biological equivalences.

## RQ3 — Can the architecture scale?
Investigate observed rules → generative model → larger synthetic architecture rather than direct graph copying.

## RQ4 — What should be preserved?
Candidate targets: degree, weight, sparsity, motifs, modularity, hubs, inter-module connectivity, path lengths, recurrence and activity statistics.

## RQ5 — Does connectome structure improve computing?
Measure accuracy, robustness, sample efficiency, latency, memory, communication, parallel efficiency and energy proxies.

## RQ6 — Which properties generalize beyond the fly?
Separate fly-specific properties from candidate general principles, using human neuroscience as an independent reference.

## RQ7 — Can one architecture support multiple workloads?
Test perception/classification, sequence processing, graph reasoning, control, decision making, memory and sparse event processing.

## RQ8 — What is genuinely new?
Maintain an explicit prior-art log. No novelty claim should be made until competing approaches are compared.
